# 한림 클래스파인더

한림대학교 강의실과 교내 시설 위치를 빠르게 찾는 학생 제작 비공식 웹사이트입니다.

- 강의실 번호·건물명·시설명 검색
- 캠퍼스 지도 위치 표시
- 카카오맵 전환, 캠퍼스 지도 휠·두 손가락 확대와 이동
- 건물 외관 및 층별 안내도, 검색한 강의실의 해당 층 도면 바로 보기
- 검색어 자동완성
- 정보 오류 제보 및 개선 의견 전달(구글 폼)

사이트: https://lh21208.github.io/hallym-class-finder/

HTML·CSS·JavaScript로 구성되어 별도 빌드 없이 GitHub Pages에서 제공합니다. 배포 파일은 저장소 최상위에 있습니다. 도면 자료에 대한 설명은 `assets/floor-plans/SOURCE.md`를 참고하세요. 일부 안내도는 오래된 자료이므로 현재 시설과 다를 수 있습니다.
